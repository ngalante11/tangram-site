### Wed — Facebook teacher group (Pillar ④) — VALUE post (no hard sell)
> **The 3-column trick that saved my mixed-ability planning:**
> Draw three columns — below / on / above grade level. For any part of the lesson that
> varies (text, task, organizer), fill in each column. Then lay your actual students on
> top: ELLs pull the language support, IEP kids get the matched accommodation, honors
> kids get the extension. The objective NEVER changes — only the access does.
> Been doing this by hand for years; recently started using a tool that builds the
> versions for me, but even pen-and-paper the 3-column method is a game changer. Happy
> to share the template if useful. 💜
